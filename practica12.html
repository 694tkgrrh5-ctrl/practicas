Práctica 12

Creacion de Base de Datos-Sentencias

¿Qué hice? En esta práctica creé una base de datos en Microsoft Access para administrar la información de miembros y productos. Primero hice tres tablas que son miembros, productos y compras Después relacioné las tablas para que Access pudiera saber qué miembro compró qué producto. También agregué algunos datos de prueba para comprobar que todo funcionara correctamente. Comandos y herramientas utilizadas Crear tablas en Vista Diseño. Crear claves primarias. Crear claves foráneas. Herramienta Relaciones. Opción Exigir Integridad Referencial. Diseño de Consulta. Ejecutar consulta (!).
