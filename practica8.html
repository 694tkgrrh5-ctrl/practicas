Práctica 8

Using CSS Counters

¿Qué hice?

En esta práctica utilicé contadores CSS para numerar automáticamente diferentes secciones de una página web. Los números se generan de forma automática sin necesidad de escribirlos manualmente.

Comandos utilizados:

  • counter-reset
  • counter-increment
  • content
  • ::before
  • CSS
Contadores CSS Anidados

¿Qué hice?

En esta práctica utilicé contadores CSS anidados para generar numeración automática en diferentes niveles de una lista. Cada elemento recibe un número de acuerdo con su posición dentro de la estructura.

Comandos utilizados:

  • counter-reset
  • counter-increment
  • content
  • ::before
  • ol
  • li
Numeración Automática de Elementos

¿Qué hice?

En esta práctica configuré una numeración automática mediante CSS para organizar y mostrar elementos de forma jerárquica. Los números se actualizan automáticamente conforme se agregan nuevos elementos.

Comandos utilizados:

  • counter-reset
  • counter-increment
  • content
  • ::before
  • CSS Counters
Contador de Visitas

¿Qué hice?

En esta práctica desarrollé un contador de visitas utilizando JavaScript. El sistema registra el número de veces que se visita la página web mediante cookies y muestra el total de visitas realizadas por el usuario.

Comandos utilizados:

  • let
  • parseInt();
  • document.cookie
  • replace();
  • getElementById();
  • textContent
  • visitas++
